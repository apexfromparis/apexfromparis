## Currently building

### OpenReverse

**OpenReverse** is an open-source reverse engineering workspace for Windows.

I'm building it as a real desktop application rather than a small demo project, with a focus on binary analysis, extensibility and a modern workflow.

Some of the areas involved include:

- PE32 / PE32+ analysis
- x64 disassembly
- Function discovery
- Cross-references
- Static and process analysis
- Memory inspection
- Strings and pattern scanning
- Control-flow analysis
- Structures and offsets
- Experimental pseudocode
- Context-aware AI integration
- Plugin architecture
- Native Windows installer
- Automated builds and testing

**Main stack**

`C++` `Windows API` `CMake` `Capstone` `Dear ImGui` `DirectX 11`
