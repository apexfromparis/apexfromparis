## Currently Building

### OpenReverse

[OpenReverse](https://github.com/apexfromparis/openreverse) is an open-source reverse engineering workspace for Windows.

The project combines low-level binary analysis, a modern desktop workflow, extensibility and contextual AI in one application.

**Current areas of development include:**

- PE32 / PE32+ analysis
- x64 disassembly
- Function discovery
- Cross-references
- Static binary analysis
- Process and module inspection
- Memory inspection
- String analysis
- Pattern and signature scanning
- Control-flow analysis
- Structures and offsets
- Experimental pseudocode
- Context-aware AI assistance
- Native Windows interface
- Native installer
- Automated testing
- Windows CI

**Main stack**

`C++` · `Windows API` · `CMake` · `Capstone` · `Dear ImGui` · `DirectX 11`

**Repository:** [github.com/apexfromparis/openreverse](https://github.com/apexfromparis/openreverse)

## Current Technical Focus

Most of my current development time is going into improving OpenReverse.

The analysis pipeline is progressively moving toward:

**Binary / Process**  
↓  
**PE Analysis**  
↓  
**Disassembly**  
↓  
**Functions**  
↓  
**CFG + Xrefs + Strings**  
↓  
**Globals / Data**  
↓  
**Structures / Offsets**  
↓  
**Analysis Context**  
↓  
**AI Assistance**

The goal is to connect analysis systems together instead of building isolated features.
